# M6 Release candidate

## What changed

- **Structured logs:** JSON lines with a `requestId` on every request, also returned as `x-request-id` (a well-formed caller ID is reused). Request logs keep method, path without the query string, and status. No headers, cookies, bodies, client addresses or host names are logged.
- **Actionable reports:**
  - Failed syncs log `feed_sync_failed` with the city, reason and next action, and show in `/admin#feeds` with a Retry button.
  - Email delivery failures are listed in `/admin#mail`.
- **Startup validation:** production refuses a missing `DATABASE_URL`, a missing or non-https `APP_ORIGIN`, `DEV_OUTBOX`, the simulated feed, turning off admin two-step sign-in, and unavailable mailers. Every problem is listed at once.
- **Migration check:** `npm run migrate:check` confirms versions run 1 to n with no gaps, a fresh apply works, and a second run applies nothing.
- **CI:** `.github/workflows/ci.yml` runs the type check, Vitest on PGlite and on a PostgreSQL service, the migration check, a production build, and a Playwright smoke test against the built app.
- **Backup drill:** `scripts/restore-drill.mjs` dumps, restores into a `_test` database, compares row counts and deletes the dump.
- **Hosting path, rollout and rollback:** [docs/DEPLOY.md](../DEPLOY.md). `docker-compose.yml` now passes `APP_ORIGIN` and `SESSION_HOURS`, and `.env.example` lists every new setting.
