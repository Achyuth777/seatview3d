Date: 2026-11-24. Branch `feat/seatview-rc`, cut from `feat/cinema-discovery` at `57739bd`. The working tree was clean, so nothing needed a backup.

## What was inspected

- **Instructions and skills:** no CLAUDE.md. Project skills: impeccable and related design skills. `DESIGN.md` defines the Reservation Chart system.
- **Scripts:** `dev`, `dev:offline`, `server`, `build`, `test`, `start`, `admin:grant`. Playwright 1.65.0 was added for E2E.
- **Database:** PostgreSQL 18 locally, PGlite fallback. Migrations `001`–`004`; `004_platform.sql` holds cities, cinemas, aliases, auditoriums, films, screenings, feed state, users, sessions, favourites, saved screenings, ratings and the admin audit log.
- **API:** Fastify routes for booking, discovery, accounts and admin (`server/app.ts`, `server/platform/routes.ts`).
- **Auth:** email and password (scrypt), HttpOnly session cookie, server-side roles, first admin granted from the CLI. There is no email verification, password reset or MFA yet.
- **3D renderer:** three.js with React Three Fiber and camera-controls. It loads on every page.
- **Hosting:** Vercel builds the frontend only (`vercel.json`, in-browser booking mode). The API and PostgreSQL are not hosted.

## Findings

1. Uncaught `Failed to fetch` on the booking page during an outage.
2. Phone landing: the first screen shows the demo schedule, and no real cinemas appear.
3. Phone seat preview: about a third of the screen is empty black, with no seat map, and the only way to choose a seat is tapping tiny 3D seats.
4. No scroll or focus restoration when going back.

## Implementation sequence

1. M2: two destinations, a thumb-reach city and search control, the Demo section, scroll and focus restoration, and the outage error fix.
2. M3: a lazy-loaded seat preview with a 2D seat map, one-update selection, compare mode, a mobile sheet, reduced motion and a WebGL fallback.
3. M4: provider-link and layout-verification tables, feed expiry, email verification, password reset, session expiry, and exactly-once alerts.
4. M5: a separate admin entry point and sign-in, TOTP MFA, the freshness proof and immediate revocation.
5. M6: structured logs without personal data, CI, backup restore and release docs.
